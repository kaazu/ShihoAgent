# 七咲しほ と あそぼう（ShihoAgent）

3Dの七咲しほに、ことばでおねがいすると動いてくれる Web デモです。
Unity（WebGL）で作っています。

**あそぶ: https://kaazu.github.io/ShihoAgent/**
（はじめての読み込みに少し時間がかかります。スマホでもあそべます）

## あそびかた
- 画面下の入力欄に「ソファに行って」「おどって」「こっちきて」などと書いて送信
- 例のボタンを押しても OK
- なにも言わないと、しほは部屋の中で自由にすごします

### わかることば
- 場所: まんなか / ソファ / 本棚 / 窓 / テーブル / お花（「〇〇に行って」「〇〇を見て」）
- こっちきて / こっち見て
- おどって / わらって / おこって / かなしい / びっくり
- とまって / すきに あそんで
- こんにちは / かわいい / なまえは？ など

### ともだちを よぶ
- 「ともだちを よぶ」で手持ちの VRM（VRoid など）をえらぶと、しほの部屋に遊びにきます
  - ファイルはブラウザの中だけで読み込みます（どこにも送りません）
- 来たら2人で自己紹介して、いっしょにおどります。そのあとはそれぞれ自由にすごします
- 名前（VRM に書かれた名前）で呼びかけると、その子が動きます
  - 「〇〇、おどって」「〇〇、ソファに行って」… その子だけ
  - 「みんなで こっちきて」「みんなで おどって」… 全員
  - 「しほ、〇〇のところに行って」… 行き先に名前も使えます
  - 「〇〇 ばいばい」… 帰っていきます
- 同時に 3 人まで
