# 七咲しほ と あそぼう（ShihoAgent）

3Dの七咲しほに、ことばでおねがいすると動いてくれる Web デモです。
Unity（WebGL）で作っています。

**あそぶ: https://kaazu.github.io/ShihoAgent/**
（はじめての読み込みに少し時間がかかります。スマホでもあそべます）

## あそびかた
- 画面下の入力欄に「ソファに行って」「おどって」「こっちきて」などと書いて送信
- 例のボタンを押しても OK
- なにも言わないと、しほは部屋の中で自由にすごします

### わかることば
- 場所: まんなか / ソファ / 本棚 / 窓 / テーブル / お花（「〇〇に行って」「〇〇を見て」）
- こっちきて / こっち見て
- おどって / わらって / おこって / かなしい / びっくり
- とまって / すきに あそんで
- こんにちは / かわいい / なまえは？ など
